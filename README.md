# Muskan Gupta — UX Portfolio

A static HTML, CSS and JavaScript portfolio designed for free hosting on GitHub Pages.

## Files
- `index.html` — page content and project cards
- `style.css` — visual design and responsive layout
- `script.js` — small interactions

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your email address.
2. Replace the LinkedIn and Behance profile links with your own profile URLs.
3. Review project descriptions and update them to match your final case studies.

## Add another case study
Duplicate one `<article class="project-card ...">...</article>` block inside `.project-grid` in `index.html`, then update its title, description, link and visual.

## GitHub Pages
In your GitHub repository, open Settings → Pages. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
